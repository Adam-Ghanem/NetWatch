# NetWatch visual assets

The SVG files in this directory are product previews rendered with sample data. They document the current dashboard direction without exposing real network identifiers.

For release screenshots or recordings:

1. Start NetWatch locally with a disposable test database.
2. Use private RFC1918 sample addresses only.
3. Remove hostnames, usernames, employer names, school names, and real asset details.
4. Capture Overview, Port audit, and Risk advisor at 1440 px or wider.
5. Keep demo recordings under 20 seconds and show the authorization confirmation before a scan.

Never commit screenshots containing real customer, employer, school, or home-network information.
